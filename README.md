# LearnHub

大学生学习科研一体化桌面应用，基于 Electron 构建，主打三大核心特性：

- **论文流式学习**：内置 PDF 阅读器 + 搜索思维链路，读论文时划选即可搜索、AI 解释、生成思维导图
- **GitHub 同步**：学习数据本地 JSON/Markdown 存储，一键与远程仓库双向同步
- **模块化拓展**：子母模块架构，第三方模块经权限契约与二次确认后安装运行

## 功能一览

### 论文阅读器（pdfjs）

- 文本高亮（四色）、批注、AI 解释；相同文本在后文出现时自动继承标记与解释
- 全文搜索：Ctrl+F 查找、Enter/F3 循环跳转、结果列表直达、页内命中高亮
- 目录大纲、缩略图导航（懒渲染 + 标注角标）、页码直达、阅读进度显示
- 引用内链跳转（点击 [12] 类标注直达目标页）、标注回跳（由笔记侧栏发起）
- 夜间反色、锁色连刷、缩放保位（Ctrl+滚轮/快捷键/按钮均保持阅读位置）
- 自动滚屏跨页续读、完整快捷键体系（Esc 按优先级逐层关闭）
- 标注导出 Markdown、划选快捷操作（搜索 / AI 解释 / 制卡 / 引用复制）

### 学习工具链

- **思维链路**：搜索历史与思维导图合并，点击节点回跳对应层级搜索记录
- **待办 / 日历 / 课表**：FullCalendar 日历视图，课表支持单双周、周次与课时配置
- **闪卡 / 生词本**：阅读器一键收词，答案可从选区快速补充
- **复习规划**：艾宾浩斯曲线自动生成复习节点
- **精读向导 / 导出复习稿**：AI 流式生成论文导读，多选论文汇总导出结构化 Markdown
- **番茄钟 / 统计**：专注会话记录与学习数据统计

### 成就系统

- 学习行为产出积木，积木搭建「成就大楼」解锁新成就，形成正反馈闭环
- 画布支持滚轮缩放（0.6x~3x，光标锚点）与右键/中键拖拽平移
- 四套场景（草原 / 沙漠 / 樱庭 / 星夜），装饰动画（飞鸟、驼队、灯笼、旋转灯塔光束、流星等）按历史最高楼高解锁，全部 CSS/SMIL 实现零运行时开销
- 连击计数、破纪录浮字、里程碑横幅、成就达成即时提醒

### 模块系统

- 子模块基于宿主默认 API 开发；需要高权限能力时由母模块（元模块）代为申请
- 模块安装时列出所申请的额外权限，用户二次确认后才可装入
- 内置示例模块见 `modules/` 目录，开发规范见 [docs/MODULE_DEV_GUIDE.md](docs/MODULE_DEV_GUIDE.md)

### 安全设计

- 渲染进程 sandbox 强制开启，特权 IPC 仅信任主框架来源
- 路径穿越、符号链接逃逸、模块 ID/清单格式校验
- GitHub 同步仅限白名单路径，含 API Key 的配置文件排除在同步范围外
- API Key 仅本地存储注入使用，不上传任何第三方服务
- 17 项安全契约测试（`npm run test:security`）作为权限改动的守门员

## 技术栈

Electron 33 · React 18 · TypeScript 5 · Vite 5（electron-vite）· Tailwind CSS · Zustand · pdfjs-dist · React Flow · FullCalendar · KaTeX

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式（热更新）
npm run dev

# 类型检查
npm run typecheck

# 安全契约测试
npm run test:security

# 生产构建
npm run build

# 打包 Windows 安装包（输出至 release/）
npm run build:win
```

## 项目结构

```
src/
  main/        # Electron 主进程（窗口、IPC、安全校验、同步服务）
  preload/     # 预加载脚本（主窗口与 webview 两套）
  renderer/    # React 渲染端
    src/components/   # 视图组件（阅读器、思维导图、内置模块等）
    src/stores/       # Zustand 状态（论文、标注、待办、成就、积木等）
    src/kernel/       # 模块内核（权限、事件总线、API 分发）
modules/       # 内置模块示例（可直接安装体验）
docs/          # 模块开发指南
tests/         # 安全契约测试
```

## 数据与同步

所有学习数据以 JSON/Markdown 存储在本地应用数据目录，GitHub 同步为可选功能，用户配置个人仓库令牌后按白名单路径双向同步；断网状态下全部功能可用。
